Let $\mathcal{T}$ be a tannakian category over an

algebraically closed field $k$. Your questions amounts to :

does $\mathcal{T}$ always have a fiber functor over $k$. I 

believe it is true. The following argument is presumably

too pedestrian, hiding which "compacity arguments" are 

really relevant.

Let $A$ be the set of strictly full subcategories

of $\mathcal{T}$, stable by $\otimes$, subquotients and duals. Let $A_\delta \subset A$

be the set of those generated by finitely many objects, using the same

operations. For $\alpha \in A$, I note $\mathcal{T}_\alpha$ the corresponding

subcategory (as defined $\mathcal{T}_\alpha = \alpha$). The set $A$ is ordered by

inclusion. I assume we already know the existence and 

unicity up to isomorphism of fiber functors for the $\mathcal{T}_\alpha$, $\alpha \in $

If $\mathcal{T}_\alpha \subset \mathcal{T}_\beta$, it makes sense to say that a 

fiber functor $\omega_\beta$ on $\mathcal{T}_\beta$ extends (on the nose) a fiber 

functor $\omega_\alpha$ on $\mathcal{T}_\alpha$. If an extension up to isomorphism

exists, an actual extension exists too.

Let us order the set of $(\alpha, \omega_\alpha)$ : $\alpha \in A$, $\omega_\alpha$

fiber functor on $\mathcal{T}_\alpha$, by "$\omega_\beta$ extends $\omega_\alpha$". To avoid

set theoretical difficulties, one could consider only the 

fiber functor $\omega_\alpha$ such that the $\omega_\alpha( X )$ take values

in the set of vector spaces $k^n$, $n \in \mathbb{N}$.
